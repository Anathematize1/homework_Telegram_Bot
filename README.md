# Homework Telegram Bot
Telegram-бот для отслеживания статуса проверки домашних заданий через API Яндекс Практикума.


## 📌 Описание проекта:
  Homework Telegram Bot — это приложение, которое автоматически проверяет статус домашнего задания через API Яндекс Практикума и отправляет уведомления пользователю в Telegram.
  Бот периодически делает запросы к API, обрабатывает полученные данные и информирует о результатах проверки.


## 🚀 Функциональность:

  ### 🔗 Работа с API:
  - отправка HTTP-запросов к API Яндекс Практикума  
  - обработка JSON-ответов  
  - получение информации о статусе проверки заданий  
  
  
  ### 🤖 Telegram-бот:
  - отправка уведомлений в Telegram  
  - интеграция с Telegram Bot API  
  - обработка входящих и исходящих сообщений  
  
  
  ### ⚙️ Логика работы:
  - периодическая проверка обновлений  
  - сравнение статусов заданий  
  - отправка уведомлений при изменении статуса  
  
  
  ### ⚠️ Обработка ошибок:
  - обработка ошибок API  
  - логирование событий  
  - устойчивость к сбоям соединения  


## 🛠 Стек технологий:
- Python  
- TeleBot
- HTTP (requests)  
- JSON  
- logging  


## ⚙️ Запуск проекта:
1. Клонировать репозиторий:
```bash
git clone <repo_url>
cd homework-bot
```
2.Создать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux / Mac
venv\Scripts\activate     # Windows
```
3.Установить зависимости:
```bash
pip install -r requirements.txt
```
4.Создать файл .env и добавить переменные окружения:
```env
PRACTICUM_TOKEN=your_token
TELEGRAM_TOKEN=your_token
TELEGRAM_CHAT_ID=your_chat_id
```
5.Запустить бота:
```bash
python homework.py
```
